# 採用コスト改善くん 紹介サイト（LP）

求人広告代理店向けの紹介ページです。ビルドの仕組みはなく、HTML・CSS・JS だけの静的サイトです。

- 確認用URL: https://kaisora-2327.github.io/saiyo-cost-kaizenkun/
- 公開予定のURL: https://lp.saiyokaizen.jp/ （DNSは未設定）

## ファイル構成

```
index.html        ページ本体（文言・構成はすべてここ）
assets/style.css  スタイル（色・書体は先頭の :root で定義）
assets/main.js    製品ツアーのタブ切り替えと、お問い合わせフォームの入力チェック
assets/robot.png  ロゴとキャラクターの画像
CNAME             GitHub Pages の独自ドメイン設定（lp.saiyokaizen.jp）
```

## 手元で見る

`index.html` をブラウザで開けば表示されます。サーバーで確認する場合は次のとおりです。

```
npx serve .
```

## デザインの決まりごと

- 色は `assets/style.css` 先頭の `:root` の変数で管理しています。製品画面のUXモックに合わせ、メインの青は `#004B9E`、文字色は `#0B2239` です。ダークモード用の値も同じ場所にあります。
- 書体は、見出しが Manrope と Noto Sans JP、本文が Noto Sans JP です（どちらも Google Fonts）。数字も Manrope にしています。等幅の書体は 0 の中に点が入るため使っていません。
- レイアウトは 960px と 560px で1列に切り替わります。

## 文言の出典

- 機能・導入効果・料金・運用体制・AI利用枠: 商品紹介スライド「採用コスト改善くん_商品紹介Ver8.pptx」
- 製品ツアー（6画面の構成）: 製品画面のUXモック
- キャッチコピー・見出し・ID数無制限の訴求・ロゴ: キャリアインデックス 星様からのご指摘（2026年11月）
- 利用規約・プライバシーポリシー: https://salesx.co.jp/terms_of_service.html へのリンク

## 未確定・仮置きのもの

- お問い合わせフォーム: 送信先が未設定です。送信を押すと「プレビューのため送信されません」と表示されます（`assets/main.js`）。
- 料金の税込・税抜の表記がありません。
- 対象媒体の表記（Indeed／求人ボックス／バイトル／その他媒体）は、スライドVer8に合わせています。モックや連携予定の媒体とは異なります。
- 画面イメージ内の媒体名（媒体A〜D）・社名・金額・件数はすべて表示例です。
- 「掲載運用」と「媒体データの自動取り込み」は、開発予定として表示しています。
- 検索エンジンに載らない設定（`<meta name="robots" content="noindex, nofollow">`）が入っています。正式に公開するときに外してください。

## 公開（GitHub Pages）

`main` ブランチのルートをそのまま公開しています。別の環境に移す場合は、このリポジトリの Pages を停止し、`CNAME` を削除してください。
